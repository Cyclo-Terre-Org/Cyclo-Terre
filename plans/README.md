# Plans

Plans de fabrication — licence [CERN-OHL-S v2](../LICENSE.md).

- **PDF** : plans cotés à imprimer pour l'atelier (A4 ou A3). Le cartouche indique la pièce, la
  matière, la quantité, la version et la date.
- **DXF** : contours à l'échelle 1:1 pour la découpe (laser, plasma, jet d'eau).

Nommez chaque fichier comme la pièce dans la nomenclature : `P012-patte-porte-outil.pdf`,
`P012-patte-porte-outil.dxf`.
