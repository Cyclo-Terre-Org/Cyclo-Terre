# CAO

Fichiers de conception du Cyclo-Terre — licence [CERN-OHL-S v2](../LICENSE.md).

- Logiciel de référence : [À COMPLÉTER]
- Unités : millimètres
- Chaque pièce existe en deux formats : le fichier natif (pour modifier) et un export **STEP** (pour
  l'ouvrir avec n'importe quel logiciel, par exemple FreeCAD).

| Dossier (proposition, à adapter) | Contenu |
| --- | --- |
| `assemblage/` | Assemblage complet de la machine |
| `cadre/` | Cadre avant, cadre arrière, porte-charge |
| `direction/` | Fourche, potence, guidon |
| `transmission/` | Pédalier, supports, tendeur |
| `porte-outil/` | Attache et réglage de hauteur des outils |

Les outils (sarcloir, semoir…) ont leurs propres fichiers dans [`../outils/`](../outils/).
