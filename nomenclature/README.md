# Nomenclature

Liste de toutes les pièces du Cyclo-Terre — licence [CERN-OHL-S v2](../LICENSE.md).

Le tableau [`nomenclature.csv`](nomenclature.csv) s'ouvre avec un tableur (LibreOffice, Excel) ou
directement sur GitHub. Une ligne par pièce :

| Colonne | Contenu |
| --- | --- |
| `reference` | Identifiant unique, repris dans les plans et l'assemblage (P001, P002…) |
| `designation` | Nom de la pièce |
| `sous_ensemble` | cadre, direction, transmission, freinage, roues, porte-outil, visserie |
| `quantite` | Nombre de pièces par machine |
| `type` | `fabrique` (plan fourni) ou `commerce` (à acheter) |
| `matiere_ou_norme` | Matière et dimensions (ex. tube inox 304 Ø25×1,5) ou norme (ex. vis ISO 4762 M6×20) |
| `fournisseur` | Où l'acheter ; plusieurs fournisseurs séparés par « ; » |
| `alternative` | Pièce équivalente si la première est introuvable |
| `prix_indicatif_chf` | Prix unitaire indicatif, hors frais de port |
| `fichier` | Plan ou fichier CAO correspondant |

Privilégiez des pièces de vélo standard, disponibles chez n'importe quel vélociste.
