# Outils

Les outils qui se montent sur le porte-outil du Cyclo-Terre. Chaque outil a son dossier, organisé
comme le dépôt principal :

```
outils/sarcloir/
  README.md        à quoi il sert, réglages, conseils d'usage
  cao/             fichiers natifs + STEP
  plans/           PDF et DXF
  nomenclature.csv
```

| Outil | Usage | État |
| --- | --- | --- |
| Sarcloir | Désherbage entre les rangs | prototype |
| Semoir | Semis en ligne sur planche de 75 cm | prototype |
| Disques butteurs | Buttage (pommes de terre, poireaux) | prototype |
| Herse rotative | Préparation superficielle du lit de semence | essai |

Vous avez conçu un outil pour le Cyclo-Terre ? Partagez-le : voir le
[guide de contribution](../CONTRIBUTING.md).
